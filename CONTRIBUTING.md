# Contributing

1. `npm run setup`, then `npm run dev`.
2. Make your change. Add or update tests (`npm test`).
3. Run `npm run scan` (secret scan) and `npx tsc --noEmit` in `apps/web`.
4. Open a pull request. Small, focused PRs are easiest to review.

Good first issues: new voices, caption styles, niche packs and templates, all of which can be plugins (see docs/PLUGINS.md).

Be kind: see CODE_OF_CONDUCT.md. Report security problems privately: see SECURITY.md.
